## 前提
1. **目的**：Transformer の代わりに Memory Mosaics を使ったモデルを作り、それが Transformer より良いことを示す
2. **Memory Mosaics とは**：論文どおりの構成のこと。すべての層で、注意を文脈の記憶に、前向きの層（MLP）を持続の記憶に置き換えたもの。元の注意を残した形や、一部の層だけを置き換えた形は、Memory Mosaics とは呼ばない
3. **比較**：
   - 比べるのは Memory Mosaics と Transformer の 2 つ
   - 同じデータ・同じ学習量（計算量）・同じ評価で比べる
   - 他の構成（混成、窓だけ、注意型の記憶など）を混ぜた比較は、主張の根拠にしない
4. **判定**：「より良い」の軸と基準は、結果を見る前に計画の文書に書く。判定は合格・保留・中止の三状態
5. **順番**：構成と比較の形が固まる前に、部品ごとの細かい確認に GPU を使わない。部品の確認は、全体の比較で差が出た後に、その理由を調べるためにだけ行う
