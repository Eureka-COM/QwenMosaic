# MosaicQwen 27B 段 1（層合わせ）の結果（2026-11-12）

計画：docs/plan-mosaic-qwen.md（27B 段 1、標準の学習量 3,000 万トークン）。前提：docs/PREMISES.md 第 2 版（実行時に照合）。日時は UTC。
重み：Release `mq-27b-s1`（記憶 10.14 億パラメータ、bf16、約 2GB）。

**結果**：Qwen3.8-27B の注意 16 層を置き換えた 16+16 ヘッドの公式 Memory Mosaics の層を、元の注意の出力に 1 層ずつ合わせた。
層ごとの誤差の平均は 1.00 → 0.275、PPL 比は 2.32 → 1.46、KL は 1.54 → 0.46。計画の「止める条件」（1,000 万トークンで誤差が 0.6 を切らない）には当たらなかった（0.315）。
